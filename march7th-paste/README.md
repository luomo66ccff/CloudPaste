# March7th Paste 4.0.0

无需登录的文本、代码与 Markdown 分享工具。新版保留原有分享链接、API 与 PostgreSQL 数据结构，更新中文界面、编辑器和本机记录，并统一密码与阅后即焚的读取规则。

## 4.0.0 · 星穹车票版界面

- 全新视觉系统：粉 / 冰蓝极光配色、深色星空背景、吸顶毛玻璃页头与重建的页脚；Space Grotesk 与 JetBrains Mono 字体随站点自托管（`@fontsource-variable`，OFL-1.1），符合现有 CSP 的 `font-src 'self'`。
- 首页重做：编辑器 + 分享车票主视觉、三种起点、工具直达、「一张车票的旅程」流程与开发者入口。
- 阅读页头部改为车票样式（主券 + 存根），编号、舱位、创建时间与有效期集中展示；公开广场卡片、密码门、状态页与 404 同步换新。
- 样式分层位于 `src/styles/`（foundation / landing / reader / workspace / adaptive），在 `app/globals.css` 之后加载；编辑器仅调整视觉属性，尺寸沿用原有断点。
- 未改动接口、数据结构、读取 / 焚毁 / 密码逻辑与编辑器行为。

## 3.2.1 的修复与维护

- CSV / TSV 转表格保留原单元格中的 Markdown 标记、HTML、实体及首尾空格；HTML 导出保留任务列表的完成 / 未完成状态。
- 创建、编辑、举报及管理接口对损坏或空 JSON 返回 400；管理隐藏操作只接受明确的布尔值，错误输入不会更改已有状态。
- 写入 PostgreSQL text 的正文、标题、语言和举报原因拒绝 U+0000；编辑器发布前提供提示，不会静默删去字符或改变本机转换结果。密码仍按原规则处理。
- 定时清理在 CRON_SECRET 缺失时返回 503，未通过凭证验证时返回 401，不执行删除。
- React / React DOM 同步更新到 19.2.8；保留 Next.js 16.4 与现有数据库结构。

- 预览组件 memo，避免源文滚动与选区变化时重复解析。正文、密码与管理凭证不会写入工具收藏或显示偏好。

## 新版功能

- 可搜索、分类和收藏的 52 项统一工具箱：链接、图片、语言代码块、自定义行列与对齐表格、有序列表、分隔线及删除线；行缩进、复制、删除、移动、排序、去重与空白清理；大小写、ASCII 全半角、URL、UTF-8 Base64、HTML 实体及 JSON 字符串转换。
- 工具箱说明处理范围，批量整理与转换支持选区或全文；失败时保持原文，成功时可以单步撤销。正文支持 `Ctrl / Cmd + B / I` 加粗/斜体、`Ctrl / Cmd + [ / ]` 调整缩进、`Ctrl / Cmd + D` 复制行和 `Alt + ↑ / ↓` 移动行；Tab 保留焦点导航。
- 多草稿工作区：12 份独立草稿、单份 512 KiB、正文合计 2 MiB；重命名、复制、删除、备份恢复，带版本冲突保护与 v2 草稿迁移。
- 查找与逐个/全部替换、有界撤销重做（最多 80 项 / 4 MiB）、Markdown 结构插入，以及保留大整数、负零、重复键原文的 JSON 校验、格式化和压缩。
- 可调整字号和逻辑行号，下载尚未发布的完整正文；手机默认单栏编辑，常用工具直接可见，工具箱为独立抽屉，分享设置可折叠。
- 阅读目录与唯一锚点、阅读进度、字号、源文切换、代码行号与换行、独立代码块复制。普通片段可主动派生为新的本机草稿。
- 18 个可搜索模板，公开片段按类型、语言、时间筛选，卡片/列表切换与分页；本机收藏、置顶、归档和到期筛选。
- `Ctrl / Cmd + K` 快捷命令，支持页面跳转、编辑命令和系统主题；系统分享与本机二维码生成/下载，不引入二维码外部服务。

- 中文首页、公开片段、最近片段、编辑器与分享页面，支持明暗主题和移动端布局。
- Markdown、纯文本、代码三种内容类型；支持 GFM、数学公式与代码高亮。
- 编辑、预览、分屏和专注模式，提供格式工具、自动换行、文本粘贴，以及 UTF-8 文本和常见代码文件的导入、拖放。
- 动态加载预览组件；超过 100,000 字符时只截断预览，提交仍使用完整正文。编辑器预览在本机渲染，不加载 Markdown 中的远端图片。
- `Ctrl / Cmd + Enter` 提交，`Ctrl / Cmd + S` 保存本机草稿，`Esc` 退出专注模式。
- 默认仅链接可见，也可选择公开；支持访问密码、阅后即焚，以及永久、1 天、7 天、30 天有效期。
- 标题最多 200 字符，正文最多 **512 KiB UTF-8 字节**；中文和 Emoji 同样按字节计算。
- 创建成功后可复制分享链接、Raw 链接或 Markdown 引用，按需保存管理凭证；不会自动打开阅后即焚内容。
- 保留举报、管理隐藏、过期清理与健康检查入口。

## 安装与检查

在项目目录使用与依赖要求相符的 Node.js 和 npm，按锁文件安装：

```powershell
npm ci
npm run lint
npm test
```

`npm test` 使用 Vitest 和进程内 PGlite PostgreSQL，加载项目已有 SQL 迁移，并替换生产数据库入口；测试配置不加载 `.env`，不连接真实数据库。覆盖密码访问、管理令牌、生命周期、并发读取、有效期保留、字节上限和 API 兼容性。具体范围见 [tests/README.md](tests/README.md)。

这些命令用于在当前环境执行检查，本文件不声明某次运行已通过。生产构建使用 `npm run build`；构建前应先确定目标站点地址。

## 隔离的本机生产预览

无需 Neon 连接串即可预览。先将公开站点地址设为本机地址，再构建和启动：

```powershell
$env:NEXT_PUBLIC_SITE_URL='http://127.0.0.1:3117'
npm run build
npm run preview:local
```

浏览器打开 <http://127.0.0.1:3117>。该入口运行真正的 Next.js 生产服务器，仅监听本机回环地址；[scripts/local-preview.mjs](scripts/local-preview.mjs) 将数据库请求转到进程内 PGlite，使用临时数据库连接配置和随机测试密钥，不连接生产 Neon 数据库。

每次启动都会新建临时数据库并放入示例片段。**停止或重启后，本次预览创建的数据和管理凭证会失效**，不适合保存正式内容。浏览器自身的草稿和最近记录遵循浏览器存储生命周期，可能在服务重启后继续显示旧记录。

使用 `Ctrl + C` 停止预览。若更换端口，应在构建前同时设置 `PASTE_PREVIEW_PORT` 和对应的 `NEXT_PUBLIC_SITE_URL`。本机预览产物中的公开地址可能在构建时固定；准备其他环境的构建时，应改为该环境的地址并重新构建。

## Neon 生产配置

正常运行通过 Drizzle ORM 和 `@neondatabase/serverless` 访问 Neon PostgreSQL。本机隔离预览使用的 PGlite 适配器不属于生产数据库配置。

在目标环境的密钥管理中提供以下配置，不要把真实值提交到仓库或写入公开文档：

| 配置项 | 用途 |
| --- | --- |
| `DATABASE_URL` | Neon 提供的 PostgreSQL 连接字符串，使用其要求的 TLS 配置。 |
| `NEXT_PUBLIC_SITE_URL` | 站点的完整 HTTPS 来源地址，不含末尾斜杠；构建前配置，用于生成分享和管理链接。 |
| `EDIT_TOKEN_SECRET` | 编辑、删除令牌和密码访问凭证的签名密钥；已有站点应保留原值。 |
| `ADMIN_TOKEN` | 管理页面及管理 API 的访问令牌。 |
| `CRON_SECRET` | 过期清理接口的 Bearer 凭证，应在生产环境配置。 |

更换 `EDIT_TOKEN_SECRET` 会影响现有管理令牌和已解锁的访问凭证。普通开发命令为 `npm run dev`，标准生产启动命令为 `npm start`；这两条命令使用正常环境配置，**不等同于隔离预览**。

本次升级未修改数据库 schema，没有新增迁移。已使用原有结构的数据库无需因本次升级生成或追加迁移。全新数据库需要具备项目 `drizzle/` 中现有迁移对应的 `pastes`、`rate_limits`、`reports` 表结构；初始化应独立审阅和安排，本说明不会自动迁移或部署生产环境。

## API 与数据兼容

原有随机 slug、分享地址、管理令牌哈希、密码哈希及生命周期字段继续使用。数据库表与现有迁移保持兼容。

| 方法与路径 | 行为 |
| --- | --- |
| `POST /api/pastes`、`POST /api/paste` | 创建片段，两种路径均保留。 |
| `GET /api/pastes/[slug]` | 读取 JSON；执行密码、可用状态及阅后即焚校验。 |
| `POST /api/pastes/[slug]/unlock` | 校验访问密码并写入兼容的 `mp_[slug]` Cookie，本身不消耗一次性读取。 |
| `PUT /api/pastes/[slug]` | 使用 `x-edit-token` 或 `?key=` 修改片段。 |
| `DELETE /api/pastes/[slug]` | 使用 `x-delete-token`、兼容的 `x-edit-token` 或 `?key=` 删除。 |
| `GET /raw/[slug]` | 返回 UTF-8 纯文本；同时保留 `.txt`、`.md`、`.markdown` 后缀。 |
| `HEAD /api/pastes/[slug]`、`HEAD /raw/[slug]` | 检查访问状态，不返回正文、不消耗阅后即焚读取。 |
| `GET /health` | 健康检查。 |

创建输入继续接受 `contentType` 和旧的 `type` 别名。响应保留 `editToken`、`deleteToken`、`url`、`rawUrl`、`rawMarkdownUrl`、`editUrl`、`deleteUrl`，以及 `raw`、`raw_txt`、`raw_md`、`edit_url`、`delete_url` 旧字段。

创建时省略 `expiresIn` 表示永久有效；编辑时省略则保留现有效期。编辑页面的「保留现有有效期」不会发送新值；密码留空保留原密码。编辑和删除页面继续识别原有 `key`、`token` 查询参数，并在验证令牌后显示管理内容。

JSON 和 Raw 读取受密码保护的片段时，需要先解锁并带上访问 Cookie，未授权返回 `401`；已经阅后即焚返回 `410`；不存在、过期或隐藏的片段返回 `404`。分享页面展示密码门禁或相应的不可用提示。读取接口不缓存正文。受密码保护或阅后即焚的片段不会进入公开列表；正文页面的 HEAD 和已识别预取请求不会触发读取。更多字段说明见站内 `/api-docs`。

## 隐私与生命周期边界

「仅链接可见」表示不进入公开发现列表，获得链接的人仍可访问。访问密码用于控制读取，服务器保存密码哈希；这不是端到端加密。

**阅后即焚表示首次成功读取后，分享链接停止提供正文。** 页面、Raw 与 JSON API 使用同一套原子读取条件，并发请求中只有一个读取赢家。它不承诺数据库或备份中的物理擦除，也无法移除读者已经复制、下载或保存的副本。

普通新建片段默认自动保存为独立本机草稿，可取消勾选；已有草稿在资料库中选择恢复，无需先丢弃其他草稿。编辑模式、设置了密码或开启阅后即焚时禁止持久化正文；敏感切换与发布只按 id/revision 清理当前版本，不删除其他草稿或其他页面的新版本。草稿不跨设备同步，也不包含访问密码或管理密钥。

草稿写入使用 Web Locks 与 revision 校验，另一个标签页修改后会暂停自动保存，并支持另存为新草稿。没有 Web Locks 的旧浏览器保留只读资料库与导出能力，可继续编辑、下载正文和创建分享，但不写入草稿。存储异常或损坏时保留原始数据，不以空库覆盖。

草稿备份文件包含本机正文；导入只创建独立副本，整批检查数量、UTF-8 正文总量和格式后原子写入。备份 JSON 可因字符转义扩大，导入文件上限为 16 MiB，实际正文仍遵守 2 MiB 总上限。

「分享记录」和「收藏夹」各保存最近 40 个链接及必要元数据，不保存服务器正文、密码或管理凭证。置顶、归档另存状态。移除本机记录不会删除服务器上的片段。

编辑和删除链接属于管理凭证。它们不会默认写入本机记录；只有明确保存或导入管理凭证时才写入 `sessionStorage`，或通过显式下载保存为 JSON。资料库可导入本站管理凭证并直接进入编辑/删除页面，服务器在实际操作时验证权限。下载的 JSON 不含访问密码和正文，但持有其中管理链接的人仍能管理片段，应自行妥善保管。
