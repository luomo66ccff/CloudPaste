# 隔离回归验证

运行 `npm test`。测试使用 Vitest 和进程内 PGlite PostgreSQL，按顺序加载项目现有的三份 SQL migration；每例测试前清空临时表，退出时销毁数据库。

`@/db` 在模块加载前被替换，生产数据库驱动不会被导入。Vitest 禁止加载 `.env`；令牌签名仅使用固定测试密钥。测试不访问真实数据库，也不会发送外部网络请求。

覆盖密码解锁及旧 Cookie、错误管理密钥、公开发现、过期及隐藏状态、UTF-8 字节上限、过期时间保留、创建与管理 API 兼容、并发读取及阅后即焚、HEAD 和预取保护。

异步页面由测试直接调用并检查返回的 React 内容，客户端组件使用简化替身。真实 Next 路由调度、浏览器交互、样式、部署和 Neon 服务仍需独立的端到端验证；这些测试不接入生产服务。

`client-storage.test.ts` 使用独立内存存储与锁队列，覆盖多草稿迁移、并发 revision、无修改保存、敏感/提交版本清理、损坏数据保护、UTF-8 与数量配额、备份原子导入、转义膨胀后的恢复、凭证白名单、分享 URL 净化和标题锚点。

`editor-tools.test.ts` 覆盖字面查找、大小写、替换及大小上限、选区/光标、Markdown 结构、撤销重做边界、JSON 词法保持、格式错误和界面偏好白名单。编辑历史只在当前页面内存中保存。

`editor-operations.test.ts` 覆盖行编辑与完整行选区、换行边界、文本和编码转换、Unicode 与错误解码、Markdown 地址校验、代码围栏、自定义表格以及 UTF-8 字节上限。转换不会执行 HTML、访问链接或调用外部服务。

`editor-utilities.test.ts` 覆盖 13 项本机工具的 Unicode、CRLF、完整行选区、512 KiB 上限、CSV / TSV 引号和记录限制、命名转换及无网络 URL 提取。

`editor-document.test.ts` 覆盖源文目录、行定位、CRLF / textarea 偏移映射、Unicode 统计、安全裸换行及 HTML 标题转义。

3.2.1 回归覆盖损坏 / 空 JSON、管理隐藏严格布尔校验、缺少清理凭证时禁止删除，以及创建 / 编辑 / 举报的 NUL 字符拒绝。CSV / TSV 使用真实 Markdown 渲染比较字面单元格内容；HTML 导出任务状态与发布前提示通过隔离预览的真实浏览器另行验证。
